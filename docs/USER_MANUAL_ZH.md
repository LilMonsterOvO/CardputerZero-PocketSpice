# PocketSpice 用户操作手册 (CardputerZero 中文版)

## 1. 46 键操作映射
- 4 ~ 8 : 底部 5 个高频功能按钮
- F / X : 上 / 下移动光标与翻页
- Z / C : 左 / 右切换电路、步进调参或切通道
- Enter : 直接输入参数数值或编辑网表行
- L     : 一键切换中文 / English 双语界面
- H     : 呼出 / 隐藏按键帮助浮层
- ESC   : 返回主列表 / 退出应用

## 2. 五大功能界面
1) CIRCUITS（电路列表与调参）:
   - 顶行按 Z/C 切换电路，按 5 可克隆为用户工程。
   - 参数行按 Z/C 步进调节，Enter 直接输值。
   - 4:运行 | 5:编辑 | 6:网表 | 7:波形 | 8:手册
2) NETLIST（原生 NGSPICE 行编辑器）:
   - 支持任意标准 NGSPICE .cir 语法！
   - 4:保存并运行 | 5:改行 | 6:+新行 | 7:保存
   - 无 @param 注释也可运行，自动识别 .tran/.ac/.dc/.op。
3) SCOPE（示波器 / Bode / 工作点）:
   - 4:重跑 | 5:切通道 | 6:缩放 | 7:回参数 | 8:截图
4) MANUAL（应用内双语手册）:
   - 5:上章 | 6:下章 | F/X 滚动 | 7:设备信息
5) INFO（512MB 内存监控与压测）:
   - 5:压测全库 | 6:切换 .save 裁剪 | 7:中/EN 切换

## 3. 内置电路与已发表论文复刻
- 01_rc_step: 一阶 RC 阶跃响应
- 02_buck_converter: PWM Buck 降压变换器
- 03_sc_doubler: 2x 开关电容倍压器
- 04_5level_sc_inverter: 五电平开关电容逆变器
  来源: Dou et al., IEEE TPEL 2026
  DOI: 10.1109/TPEL.2026.3683439
- 05_bode_rlc_filter: 二阶 RLC 滤波 AC Bode

## 4. 512 MB 内存安全守则
- 长瞬态务必保留 `.save v(...) i(...)` 裁剪输出。
- 单次步数建议控制在 50,000 点以内。
- 严禁以 root 权限运行本应用。
